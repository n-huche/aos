A internet é uma rede global de computadores interconectados usando protocolos TCP/IP.

TCP/IP é um conjunto de protocolos onde TCP e IP são os principais.

O TCP é responsável pela comunicação de forma confiável.

O IP é responsável principalmente pelo endereçamento e encaminhamento dos pacotes.

O conjunto TCP/IP de forma geral define como computadores conseguem se comunicar através de redes.

Quando um cliente quer acessar um domínio, ele consulta um servidor DNS para descobrir o endereço IP correspondente. Depois, os dados são encaminhados através de redes e roteadores até o servidor de destino.

Request é uma requisição feita por um cliente, como um navegador, aplicativo ou outro servidor, para um servidor.

ISPs são Internet Service Providers, empresas que fornecem acesso à Internet. Os dados passam pela rede do ISP e por roteadores que encaminham os pacotes para outras redes até que eles cheguem ao destino.

DNS é Domain Name System, é a "agenda telefônica" da internet, responsável por traduzir nomes de sites fáceis de lembrar em endereços IP numéricos, que os computadores usam para se comunicar. Existem diferentes servidores DNS de diferentes organizações.

Isso tudo possibilita uma comunicação global dinâmica e descentralizada.
